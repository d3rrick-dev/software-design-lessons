Learning design patterns

#### Creational patterns - How objects are created
1. [Factory](src/creational/factory/Readme.md) - Creates objects without exposing instantiation logic.
2. [Singleton](src/creational/singleton/Singleton.md) - Ensures a class has only one instance globally.
3. [Abstract Factory](src/creational/abstxractfactory/Abstractfactory.md) - Provides an interface to create families of related objects.
4. [Prototype](src/creational/prototype/Prototype.md) - Creates new objects by copying existing ones.
5. [Builder](src/creational/builder/Builder.md) - Separates object construction from its representation for step-by-step creation.

#### Collectional patterns - How groups of objects are managed or traversed
1. [Iterator](src/collectional/iterator/Iterator.md) - Provides a standard way to traverse elements in a collection.
2. [Composite](src/collectional/composite/Composite.md) - Treats individual objects and compositions of objects uniformly.
3. [Flyweight](src/collectional/flyweight/Flyweight.md) - Shares objects to minimize memory usage when many similar objects exist.
4. [Visitor](src/collectional/visitor/Visitor.md) - Adds operations to objects without changing their classes.

#### Structural -  How objects are composed and connected
1. [Decorator](src/structural/decorator/Decorator.md) - Dynamically adds behavior to objects without altering their class.
2. [Chain of Responsibility](src/structural/chainofresponsibility/Chain.md) - Passes a request along a chain of handlers until one can handle it.
3. [Facade](src/structural/facade/Facade.md) - Provides a simplified interface to a complex subsystem.
4. [Proxy](src/structural/proxy/Proxy.md) - Controls access to another object, optionally adding extra behavior (lazy loading, security, logging).
5. [Bridge](src/structural/bridge/Bridge.md) - Decouple abstraction from implementation so the two can vary independently

#### Behavioral - How objects communicate, interact, and share responsibilities.
1. [Command](src/behavioral/command/Command.md) - Encapsulates a request as an object.
